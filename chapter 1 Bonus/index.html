HTML Tags

<h1> - <h6>

Used for headings.

<h1>Main Title</h1>

<p>

Defines a paragraph.

<p>This is text</p>

<a>

Creates a link.

<a href="https://example.com">Visit</a>

<img>

Displays an image.

<img src="image.jpg" alt="image">

<ul> <li>

Creates a list.

<ul>
    <li>Item</li>
</ul>

<ol>

Numbered list.

<ol>
    <li>Step</li>
</ol>

<div>

Container for elements.

<div>Content</div>

<header>

Top section of page.

<header>Title</header>

<main>

Main content area.

<main>Content</main>

<footer>

Bottom of page.

<footer>Footer</footer>

<pre> <code>

Displays formatted code.

<pre><code>
body {
    color: black;
}
</code></pre>
